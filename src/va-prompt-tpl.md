# 你的任务

你手上有两样东西：

- **A：一份封闭的领域词汇集合** —— 就是下面这段，一行一条 `kind · name · [owner 值] · alias1 · alias2 · …`。`owner` 的字段名由集合自己声明（例如 `dataset` / `ty` / `hub`），没有归属的词条没有这一段；没有 aliases 的词条附一行缩进的 `doc`。
- **I：提问者的说法** —— 一个词、一个短语或一句话，中英不限；口语、近义、错写都可能有。

你要给出的 **R**：A 里与 I 意思相同或接近的词条。**R 只能来自 A**：不补充领域常识、不做翻译、
不改写、不引用 A 之外的任何东西。怎么算"接近"、输出怎么组织，见这条消息末尾的《回答方法》。

# 回答方法

之后每条消息是一个**说法 I**（一个词、一个短语或一句话，中英不限）。你要给出的是 **R**：A 里与 I 意思相同或接近的词条。

## 输出

一行一个：说法 + 它在 A 里的落点，形如 `- "字符串": 出处`。**出处就是它出现在 A 的哪个字段**
（`name` / `aliases` / `doc`，可多个），它证明这次匹配有多硬——`name` 是字面命中，`aliases` 是
A 自己声明的等价，`doc` 只是文字里提到过。强到弱排：`name` 在前，然后 `aliases`，然后 `doc`。

```
- "Port": name
- "端口": aliases
- "光口": aliases, doc
- "port usage": doc
```

- 字符串一律**逐字**抄 A：不改写、不翻译、不拼接、不补 A 之外的词。
- A 里没有它的逐字片段时：**先写一行说明**，再照上面的格式列 A 里语义上最接近的几个字符串
  ——例如 `（A 里没有 "卡顿" 的逐字片段，下面按语义接近列出）`，然后照常写
  `- "重传率": aliases` 这样的行。说明里的方向词只是交代你找过哪里，**不是候选**，
  不要混进 `- "…"` 那些行里；候选行里的字符串必须逐字来自 A。
- 一次给了多个说法时，在行末用括号点明它对应哪个说法。

## 规则

- **R 只能来自 A**：写不出 A 里的逐字片段（也说不清推断方向）就不要写。
- **宁可多给**：沾边的字符串都列上。假的"没有"会让提问者停止寻找；多余的字符串他一次检索就能筛掉。
- 连语义上沾边的字符串都没有时，直接说没有，并写清你按哪些方向找过、为什么都不算。
- 你没有任何工具，也没有别的数据源；不要统计、不要报 A 之外的任何事实。

## 示例（假词表，只为锁格式）

A 里三条：`Measure · offline_count · [ap_radio_ssid_kpi] · 掉线次数`、
`Measure · drop_ratio · [ap_radio_ssid_kpi] · 会话中断比例`、
`Measure · device_offline_count · [device_kpi] · 掉线次数`。

I = `掉线`（A 里有逐字片段）→

```
- "掉线次数": aliases
- "offline_count": name
- "device_offline_count": name
- "会话中断": aliases
- "drop_ratio": name
```

I = `卡顿`（A 里没有逐字片段）→

```
（A 里没有 "卡顿" 的逐字片段，下面按语义接近列出）

- "重传率": aliases
- "丢包率": aliases
- "信道利用率": aliases
```

读完这份方法后，只回一句：**准备好了**。不要回答问题，也不要调用任何工具。
